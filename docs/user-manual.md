## はじめに

Screen Audio Recorder は、Windows PC の画面とマイク・システム音声を同時に録画・録音し、音声を自動で文字起こしして「メモ」として保存するアプリケーションです。

主な特徴:

- 管理者権限なしで動作（企業環境でも利用可能）
- 画面録画 + マイク音声 + システム音声の同時録音
- 音声のみの録音モード
- ローカル AI による自動文字起こし（外部サーバーへのデータ送信なし）
- LLM によるテキスト修正・要約・テーマ自動生成
- メモの一覧管理・検索・再生

## 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 バージョン 1903 以降、Windows 11 |
| 権限 | 管理者権限不要 |
| ディスク | 初回起動時に Whisper モデル（約500MB〜3GB）のダウンロードが必要 |
| GPU（任意） | NVIDIA GTX 1050 以上で H.264 ハードウェアエンコード対応 |

## インストールと起動

### インストール

1. 配布された `screen-audio-recorder.exe`（または展開済みフォルダ）を任意の場所に配置します
2. インストーラーは不要です。管理者権限も不要です

### 起動

1. `screen-audio-recorder.exe` をダブルクリックします
2. メインウィンドウが表示されます
3. ステータスバーに「モデル読み込み中...」と表示されている間は、Whisper 文字起こしモデルをバックグラウンドで読み込んでいます
4. 読み込みが完了すると録画ボタンが有効になり、使用可能になります

> **初回起動時の注意**: Whisper モデルのダウンロードが自動で行われるため、初回は起動に時間がかかる場合があります。

## 画面構成

メインウィンドウは以下の4つのタブで構成されています。

### 録画タブ（メインタブ）

アプリ起動時に表示されるメインの操作画面です。

| UI 要素 | 説明 |
|---------|------|
| 録画モード選択 | 「画面+音声」または「音声のみ」をラジオボタンで選択 |
| マイクデバイス選択 | 使用するマイクをドロップダウンから選択 |
| 開始ボタン | 録画・録音を開始 |
| 停止ボタン | 録画・録音を停止 |
| ステータスバー | 現在の状態（モデル読み込み中、録画中、文字起こし中など）を表示 |
| メモ一覧 | 保存済みメモの一覧（下部に表示） |

### LLM 設定タブ

文字起こし後のテキスト処理に使用する LLM（大規模言語モデル）の設定を行います。

### 詳細設定タブ

ログレベルなどの詳細設定を行います。

### このアプリについてタブ

バージョン情報・作者情報を表示します。

## 基本操作

### 画面+音声モードで録画する

1. 録画モードで「画面+音声」を選択します
2. マイクデバイスを選択します（システム音声は自動で取得されます）
3. 画面上に表示される赤枠（録画領域オーバーレイ）で録画範囲を調整します
4. **「開始」ボタン** をクリックします
5. 録画中はステータスバーに録画状態が表示されます
6. **「停止」ボタン** をクリックして録画を終了します
7. 自動で文字起こしが開始され、完了するとメモ一覧に追加されます

### 音声のみモードで録音する

1. 録画モードで「音声のみ」を選択します
2. マイクデバイスを選択します
3. **「開始」ボタン** をクリックします
4. **「停止」ボタン** をクリックして録音を終了します
5. 自動で文字起こしが開始され、完了するとメモ一覧に追加されます

> **音声について**: マイク音声とシステム音声（PC のスピーカー出力）の両方が自動で録音されます。音量差は自動で補正されます。

### 録画の出力形式

| モード | 出力形式 |
|--------|----------|
| 画面+音声 | MP4（H.264 映像 + 音声） |
| 音声のみ | WAV |

## 録画領域の調整

「画面+音声」モードでは、録画する画面範囲を赤枠のオーバーレイで指定できます。

### 操作方法

| 操作 | 動作 |
|------|------|
| ドラッグ（左クリック+移動） | 録画領域を移動 |
| 右下角をドラッグ | 録画領域をリサイズ |
| マウスホイール（スクロール） | 録画領域を拡大・縮小 |

### サイズ制限

- 最小サイズ: 320×240 ピクセル
- 最大サイズ: ディスプレイの解像度と同一

> **注意**: 録画中はオーバーレイが非表示になります（画面キャプチャへの干渉を防ぐため）。

## メモの管理

録画・録音が完了すると、文字起こし結果が自動でメモとして保存されます。

### メモ一覧の見方

メモ一覧には以下の情報が表示されます:

- **作成日時**: 録画・録音を行った日時
- **テーマ**: 内容を表す短いキーワード（10文字以内、自動生成）
- **本文プレビュー**: 文字起こし内容の先頭50文字

メモは作成日時の降順（新しいものが上）で表示されます。

### メモの操作

| 操作 | 説明 |
|------|------|
| メモをクリック | 全文と要約を下部ペインに表示 |
| ▶ 再生ボタン | 録画・録音ファイルをデフォルトのメディアプレーヤーで再生 |
| 削除ボタン | メモと関連する録画ファイルを削除 |
| LLM 再処理ボタン | LLM でテーマ・要約・テキスト修正を再実行 |
| テーマをダブルクリック | テーマを手動で編集 |

### ページネーション

メモが50件を超える場合、ページ送りボタンで前後のページに移動できます。

## LLM 設定

LLM（大規模言語モデル）を使用すると、文字起こしテキストの品質が向上します。

### LLM が行う処理

1. **テキスト修正**: 句読点の補完、誤字脱字の修正
2. **要約生成**: 内容を3〜5文で要約
3. **テーマ生成**: 内容を表す10文字以内のキーワード

> **LLM なしでも動作します**: LLM が未設定の場合は、janome（日本語形態素解析）によるテーマ生成のみが行われます。

### 推論バックエンドの選択

| バックエンド | 説明 |
|-------------|------|
| ローカル（llama-server） | PC 上で LLM を実行。インターネット不要。GGUF 形式のモデルファイルが必要 |
| オンプレ API（OpenAI 互換） | 社内サーバー等の OpenAI 互換 API に接続 |

### ローカルモデルのセットアップ

1. **LLM 設定タブ** を開きます
2. 推論バックエンドで「ローカル（llama-server）」を選択します
3. llama-server が未インストールの場合は「llama-server をダウンロード」ボタンでインストールします
4. モデルファイルを以下のいずれかの方法で設定します:
   - 「ダウンロード」ボタンで推奨モデルをダウンロード
   - 「参照...」ボタンで既存の GGUF ファイルを指定
5. 「設定を保存」をクリックします
6. 「接続テスト」で動作を確認します

### ダウンロード可能なモデル

| モデル | サイズ | 特徴 |
|--------|--------|------|
| Qwen2.5 1.5B (Q4_K_M) | 約1.0GB | 最軽量・日本語対応◎ |
| Gemma 2 2B (Q4_K_M) | 約1.5GB | バランス型・日本語対応◎ |

### API バックエンドのセットアップ

1. **LLM 設定タブ** を開きます
2. 推論バックエンドで「オンプレ API（OpenAI 互換）」を選択します
3. エンドポイント URL を入力します（例: `http://server:8080/v1/chat/completions`）
4. 必要に応じて API キーを入力します
5. 「設定を保存」をクリックします
6. 「接続テスト」で動作を確認します

### 生成パラメータ

| パラメータ | デフォルト値 | 説明 |
|-----------|-------------|------|
| 最大トークン数 | 1024 | 生成テキストの最大長 |
| Temperature | 0.3 | 生成のランダム性（低いほど安定） |
| コンテキストサイズ | 8192 | 入力可能なトークン数（大きいほどメモリ使用量増） |
| タイムアウト | 600秒 | 応答待ち時間（CPU 推論は時間がかかる場合あり） |

### 文字起こし設定（Whisper モデルサイズ）

| モデルサイズ | 精度 | サイズ | 速度 |
|-------------|------|--------|------|
| tiny | 低 | 最小 | 最速 |
| base | やや低 | 小 | 速い |
| small（デフォルト） | 中 | 約500MB | 標準 |
| medium | 高 | 約1.5GB | やや遅い |
| large | 最高 | 約3GB | 遅い |

> **変更の反映**: モデルサイズの変更は次回の文字起こし時に反映されます。

### プロンプトテンプレートのカスタマイズ

LLM に送信するプロンプトを編集できます。テンプレート内の `{text}` が実際のテキストに置換されます。

- **テキスト修正**: 句読点補完・誤字修正の指示
- **要約生成**: 要約作成の指示
- **テーマ生成**: テーマ（キーワード）生成の指示

「デフォルトに戻す」ボタンで初期設定に復元できます。

## 詳細設定

### 詳細ログの有効化

問題が発生した場合のトラブルシューティング用に、詳細ログを有効にできます。

1. **詳細設定タブ** を開きます
2. 「詳細ログを有効にする（デバッグ用）」にチェックを入れます
3. 「設定を保存」をクリックします
4. **アプリを再起動** します（設定変更は再起動後に反映）

有効にすると、音量情報やストリーム診断など詳細なログが `app.log` に出力されます。

> **注意**: 詳細ログはパフォーマンスに影響するため、通常運用では無効のままにしてください。

## データの保存場所

すべてのデータは以下のフォルダに保存されます:

```
C:\Users\<ユーザー名>\Documents\screen-audio-recorder\
```

| ファイル/フォルダ | 内容 |
|------------------|------|
| `recordings/` | 録画・録音ファイル（MP4, WAV） |
| `models/` | ダウンロードした LLM モデル |
| `memos.json` | メモデータベース |
| `llm_settings.json` | LLM 設定 |
| `app_settings.json` | アプリ設定（詳細ログなど） |
| `app.log` | アプリケーションログ（5MB × 3世代ローテーション） |

## 自動更新

Screen Audio Recorder は GitHub Releases を利用した自動更新機能を備えています。

### 更新の確認

1. **「このアプリについて」タブ** を開きます
2. **「更新を確認」ボタン** をクリックします
3. 最新バージョンがある場合、バージョン番号とリリースノートが表示されます
4. 「はい」をクリックすると更新のダウンロードが開始されます

> **注意**: 録画中は更新確認ができません。録画を停止してから操作してください。

### 更新の種類

| 種類 | 内容 | サイズ目安 |
|------|------|-----------|
| 通常更新 | exe ファイルのみ置き換え | 約50MB |
| フル更新 | exe + _internal フォルダ全体を置き換え | 約200〜400MB |

更新種別はリリース内容に基づいて自動で判定されます。

### ダウンロード中の操作

- プログレスバーで進捗率がリアルタイム表示されます
- ダウンロード速度と残り時間が表示されます
- **「キャンセル」ボタン** でダウンロードを中断できます

### 更新の適用

ダウンロード完了後、更新は自動で適用されます:

1. 現在のファイルがバックアップされます
2. 新しいファイルに置き換えられます
3. アプリケーションが自動的に再起動します

> 更新中にエラーが発生した場合は、自動的に旧バージョンに復帰します。

### 前のバージョンに戻す（ロールバック）

更新後に問題が発生した場合、以前のバージョンに戻すことができます:

1. **「このアプリについて」タブ** を開きます
2. バックアップが存在する場合、**「前のバージョンに戻す」ボタン** が表示されます
3. ボタンをクリックし、確認ダイアログで「はい」を選択します
4. アプリケーションが旧バージョンで再起動します

> **注意**: 次回の正常な更新完了時に、古いバックアップは自動的に削除されます。

## トラブルシューティング

### 録画ボタンが押せない

- ステータスバーに「モデル読み込み中...」と表示されている場合は、Whisper モデルの読み込み完了を待ってください
- 初回起動時はモデルのダウンロードに数分かかる場合があります

### マイクが認識されない

- マイクデバイスのドロップダウンに表示されない場合は、Windows の「サウンド設定」でマイクが有効になっているか確認してください
- マイクが利用不可の場合、警告が表示されシステム音声のみで録音が継続されます

### システム音声が録音されない

- WASAPI ループバック録音を使用しています。音声出力デバイスが正しく設定されているか確認してください
- システム音声の取得に失敗した場合、警告が表示されマイク音声のみで録音が継続されます

### 録画の映像がカクつく

- ハードウェアエンコーダ（NVIDIA NVENC 等）が利用できない場合、CPU エンコード（libx264）にフォールバックします
- CPU エンコードは負荷が高いため、録画領域を小さくすると改善する場合があります
- 詳細ログを有効にして `app.log` でエンコーダの検出状況を確認できます

### LLM が動作しない

- 「接続テスト」ボタンで接続状態を確認してください
- ローカルモードの場合: llama-server がインストールされているか、モデルファイルのパスが正しいか確認してください
- API モードの場合: エンドポイント URL が正しいか、サーバーが起動しているか確認してください
- LLM が利用不可でも、文字起こしとテーマ生成（janome フォールバック）は動作します

### 音声と映像がずれる

- 本アプリは音声と映像の同期処理を自動で行っています（精度 0.3 秒以内）
- 大きなずれが発生する場合は、詳細ログを有効にして `app.log` の同期オフセット情報を確認してください

### ログファイルの確認方法

ログファイルは以下の場所にあります:

```
C:\Users\<ユーザー名>\Documents\screen-audio-recorder\app.log
```

テキストエディタで開いてエラーメッセージを確認できます。

### 更新の確認に失敗する

- インターネット接続を確認してください
- プロキシ環境の場合、環境変数 `HTTPS_PROXY` が正しく設定されているか確認してください
- 詳細ログを有効にして `app.log` のエラーメッセージを確認してください
